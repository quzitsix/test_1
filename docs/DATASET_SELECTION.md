# 数据源选型表 — 长期家庭空间记忆

调研覆盖六个方向、18 个 agent,每个候选的 **session 结构声明都经过独立复核**(因为那一个字段决定一切)。下面的数字凡标"实测"的,都是下载元数据后程序化算出的,不是论文摘要。

**决定性要求**:同一物理环境,在**时间上分离**的 ≥2 个 session 中被记录,且每个 session 里**物体位置可知**。一次连续录制无论多长,都远弱于五次分开的回访。

---

## 一、可用的(verdict: yes)

### 1. 3RScan ★ 结构最强,且不用下视频就能挖题

| 项 | 值 | 来源 |
|---|---|---|
| 环境数 | **478** | 实测 `3RScan.json` |
| 总扫描 | **1,482**(478 reference + 1,004 rescan) | 实测 |
| 每环境 session 数 | 2×160、3×68、4×31、5×8、6×7、7×7、9×1、**11×2**;单 session 194 个 | 实测分布 |
| **带 6DoF 的物体移动事件** | **2,933**(train 2,543 + val 390) | 实测 |
| 物体移除事件 | **542** | 实测 |
| 非刚性变化 | 558 | 实测 |
| instance ID 跨 session | **固定** —— 这就是"杯子去哪了"的原语 | 实测字段 |
| 元数据体积 | **3.01 MiB**(+ 3DSSG 标注 2.66 MiB) | 实测 HTTP 200 |

`rigid` 事件的真实字段:`{instance_reference, instance_rescan, symmetry, transform}`,`transform` 是 **4×4 行主序矩阵,平移在最后一行,单位 mm**。

> **注意 split 差异(实测)**:`test`(46 环境)的 `rigid` **只有 instance ID,没有 transform** —— 答案被官方隐藏。`train`+`validation`(432 环境)才有完整 6DoF。这反而是好事:test split 可以当我们自己的 held-out。

**3DSSG 标注层**(独立下载,**不用填表**):43,450 个物体实例、528 个标签,含 `attributes`(颜色 14,319、形状 13,499、尺寸 10,183、材质 6,211、**状态 4,141**)与 `affordances`。

- **许可**:数据需填 Google 表(TUM ToU,非商业);**3DSSG 的 zip 无需填表**。ToU 只限制再分发**数据库本身**,对衍生标注沉默 —— 发布纯文本 QA(带 scan_id/instance_id 引用)很可能可以,但建议发一封邮件到 `3RScan@googlegroups.com` 留书面记录。
- **污染:全部候选中最低。** HF 上仅 3 个镜像(最大 1,217 下载),**零个 QA 衍生版、零个微调模型**。四个已披露训练混合逐文件核查均无命中。已知暴露:SceneVerse 含约 1K 个 3RScan 场景。
- **代价**:**没有人**(静态空房间扫描)→ 撑不起 A10 人物关系轴;房间级而非全屋;**时间间隔有歧义** —— 论文说部分是"几分钟内的受控变化",部分是"数月的自然变化",而 JSON 里**没有日期字段**(程序化确认)。

### 2. SuperMemory-VQA ★ 唯一有真实数周间隔

| 项 | 值 |
|---|---|
| session | **83 个**,跨 10 人,同**一间** Airbnb 公寓 |
| 真正跨多天的人 | **仅 3 人**(person_1 五个日期、person_2 四个、person_3 三个);其余 7 人单日 |
| **实测间隔**(person_1 链) | 0.8h ×5 → **818.9h(34 天)** → 67.7h → … → **329.8h(13.7 天)** |
| 现成跨 session 题 | **169 道**,其中 **31 道 object_location_memory** |
| 总量 | 4,853 题 / 52.9 小时 |
| 几何 | 每 session 有 SLAM 6DoF 轨迹 + 半稠密点云 |

**有显式 unanswerable 选项** —— 直接对应我们的弃答控制组设计。

- **许可**:CC BY-NC-SA 4.0,**未 gated**。衍生 QA 可再分发,但 **share-alike 有传染性**(我们的发布物也必须 BY-NC-SA 兼容),这一点要报给项目许可决策人。
- **污染**:HF 上**零个微调模型**;四个已披露混合都早于其 2026 年发布,**时间上不可能包含**。残余风险:未 gated、4.7K 下载,冻结前需复查。
- **代价**:一间**租来的**公寓而非真实居所;物体位置是**自然语言 + 房间标签**,不是 metric 位姿;房间名未规范化(`kitchen`/`Kitchen`/`Apartment kitchen` 混用,需自己归一);每人 session_1 是首次进入陌生公寓,与 Toyota Smarthome 同病。

## 二、次优(verdict: partly)

| 数据集 | 强项 | 致命限制 |
|---|---|---|
| **NymeriaPlus** (2026) | 43 个家 ≥2 天;19 类物体标注**逐 session 修正移动过的物体**;CC BY-NC 4.0 最干净;污染为零 | **同一人从不在后续某天回到同一个家**(实测:236 个 participant-location 对里跨天 = **0**)。只能问"这个家变了什么",不能问"我上周把杯子放哪了"。间隔 1–2 天,不是数周 |
| **EgoMonth** (2026) | **每人 20–120 天**,738 clip / 301 小时 —— 全调研最长的人级跨度 | 匿名评审中;**视频需分级申请**;单视频 3–4 GB;环境级关联弱 |
| **ContextAct@A4H** | 同一公寓两个录制块,**相隔约 5 个月** | 无视频(仅传感器事件) |
| **LSC 18-month lifelog** | **18 个连续月**,546 天,单人 | 帧密度极低(分钟级),物体位置不可知 |
| **CASTLE 2024** | 4 天,10 人,日结构已落盘 | 仅 4 天;非住宅 |
| **RIO10 / MultiScan** | 每场景 5–12 个时间阶段 | 间隔无文档;规模小 |
| **STRANDS** | KTH-3D-TOTAL:20 张桌子 × 每天 3 次 × **19 天** | 机器人视角;桌面级而非家庭 |

## 三、重要的否定结论(别再查了)

| 类别 | 为什么不行 |
|---|---|
| **AEA**(我原本最看好) | 论文用了四次 "longitudinal",但**没有物体位姿、没有物体身份、没有任何实例标签**,只有几何点云。同一位置多次录制**是**真的,但物体位置不可知 |
| **PROSE** 论文的"跨时间"主张 | 陷阱:配对其实是 **0.5 秒采样**,不是跨天 |
| **整个智能家居传感器类**(CASAS 189 家 / 18 年、ARAS、Orange4Home、SDHAR-HOME) | **无一部署摄像头**;且都是**单条连续流**而非分离 session。有真正物体身份的只有 CASAS Kyoto,但那是单次进入的脚本化实验 |
| **SPHERE-100** | **从未公开发布**。2016 年起一直是将来时 |
| **全部机器人操作数据**(DROID、RH20T、Dobb-E、Mobile ALOHA、TidyBot++、Open X-Embodiment) | **完全没有 session 概念**。DROID 是 564 个场景 / 52 栋楼的短操作片段 |
| **BabyView / SAYCam** | 真有每周回访(31 个家庭、数月),但受限访问 + 婴儿视角 |
| **Rescan (Halber)** | 时间间隔是**假的** —— 变化由研究者摆放 |
| **Nothing Stands Still / LaMAR** | 间隔真实(月级),但变化是**结构性施工**或无家庭物体语义 |
| **Aria 其余全部**(HOT3D、DTC、AEO、ASE、A2PD、RitW) | 逐个核查:无 session、无家、或每场景仅一条轨迹 |
| **一次连续长录制类**(MobileEgo Anywhere 等) | 最大的假阳性类别 —— "long-horizon" 指单集很长,不是多次回访 |

**一个方法论警示**:调研发现 2026 年有大量"在已有语料上加 QA 层"的论文(UCS-Bench、S-EMBER、EgoMemReason 等)。它们不提供新的家,只是重新标注 —— 评估时别把它们当独立数据源。

## 四、结论与优先级

**没有单一数据集能同时满足"真实长期回访 + 多人 + 精确几何 + 低污染"** —— 这个"不可能三角"在本轮调研后依然成立。所以仍是 per-axis 挂载:

| 轴 | 挂载 | GT 强度 | 理由 |
|---|---|---|---|
| **A3 物体迁移**(主打) | **3RScan** | **exact 6DoF** | 2,933 个带变换的移动事件,零人工,**不用下视频** |
| A3 补充 / 真实周级间隔 | **SuperMemory-VQA** | 自然语言 | 169 道现成跨 session 题,34 天真实间隔 |
| A4 状态变迁 | EPIC-100 | exact | 2,624 个 open/close 配对区间,**不依赖位置口述** |
| A11 事件计数 | EPIC-100 | exact | "开了几次冰箱" |
| A12 不可回答 | 全部 | exact | 3RScan 的 `removed`(542)天然就是"东西不在了" |
| A2 度量几何 | ScanNet val 干净池 | exact | 已复现 VSI-Bench GT |
| A10 人物关系 | EgoLife(唯一) | exact | 但许可冲突未解 |

**EPIC 的 A3 降级**:实测 **0.84 道题/GiB**(21 道 / 25 GiB),而 3RScan 是 **2,933 个事件 / 3 MiB**。EPIC 保留给 A4/A11/A12 —— 那几条不需要位置口述,产量高 100 倍。
